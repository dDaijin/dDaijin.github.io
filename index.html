How the parsing works

01

Fetch

fetch() requests JSON from both APIs in parallel with Promise.all.

02

Parse

Each response is decoded with response.json(), then reshaped into a flat array of rows.

03

Render

Rows are written into the DOM with textContent — no template engine, no framework.

Built with plain HTML, CSS and JavaScript — system fonts only, no build step, no framework.
