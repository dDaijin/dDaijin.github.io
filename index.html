Why this exists

Built to be the opposite of a dark pattern.

01

No backend

There is no server here. Every calculation happens in your browser with plain JavaScript — check the network tab, it's empty.

02

No file uploads

The "document" step lets you preview a file locally to demonstrate the UI. Nothing is read, uploaded, or transmitted.

03

No persistence

Form values live in memory for this tab only. Refresh the page and it's gone — nothing is written to a database or third party.
